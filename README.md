# 🎄 Festive Pulse Dashboard

**Festive Pulse** is a single-file React dashboard that displays countdowns for upcoming global and seasonal holidays. 

---

## 🚀 Cool Features

*   **Live Countdowns:** Tracks days, hours, minutes, and seconds for major holidays.
*   **Mouse Particle Effects:** Moving or clicking your mouse drops particles that move around the screen.
*   **Built-in Sounds:** Plays synth tones and holiday songs directly through your browser.
*   **New Year Confetti:** Hits a massive confetti explosion across the screen the exact second a timer hits zero.
*   **Immersive Fullscreen:** Open up any holiday card into a clean fullscreen view to leave open on a monitor.
*   **Search & Sort:** Easily filter between categories, search for events, or toggle between Dark and Light mode.

---

## 📝 How It Runs

It's completely frontend-only. Everything loads straight in the browser from one code file with no servers required.
